# 第一章：首席舔狗的破产清算

陈凡睁开眼时，脑子里还残留着华尔街交易大厅的喧嚣，以及那道从天而降的紫色劫雷。

作为三十二岁掌控千亿对冲基金的金融巨鳄，他一生信奉“万物皆可量化，包括天劫”，甚至请了十二位物理学诺奖得主推演渡劫模型。结果证明，天道不按数学模型出牌。

“陈师兄？陈师兄你醒醒！”

耳边传来少女急促的呼唤，带着哭腔。

陈凡努力聚焦视线，首先映入眼帘的是雕花木梁上流转的淡金色符纹，以及空气中肉眼可见的淡蓝色灵气流——这完全不符合他认知中的任何物理定律。

记忆如潮水般涌来。

陈不凡，二十三岁，青云仙宗外门“首席弟子”——这个头衔全靠他百年如一日、倾尽所有资源地“舔”着内门圣女凌清雪得来。昨天凌清雪在炼丹时随口说了句“缺一味冰魄玄晶”，陈不凡便闯入极北寒域，以炼气三层的修为硬抗筑基期妖兽，终于带回晶石，却也身中寒毒，经脉尽碎。

今日他强撑病体去献宝，凌清雪接过冰魄玄晶，当着他的面随手扔给旁边的灵宠当玩具，淡淡道：“纯度太差，也就配给雪儿磨牙。”

周围弟子哄堂大笑。

陈不凡一口逆血喷出，当场昏迷。

再醒来时，壳子里已经换成了陈凡。

“真是……精彩的人生。”陈凡忍着全身如刀割般的剧痛，缓缓坐起。

他正在一间简陋的木屋里，除了一张硬板床、一张缺腿的桌子，就只有墙上挂着的破旧储物袋。床边蹲着个十四五岁、眼睛红肿的少女，穿着打补丁的外门弟子服，怀里抱着个小包裹。

“柳儿？”陈凡从记忆里翻出这个名字。柳小茹，和他一样是外门底层，父母是宗门灵田的杂役，五年前死于妖兽袭击。陈不凡见她可怜，曾分过半块馒头给她——这是原主记忆里，唯一一次不是为凌清雪而付出的“投资”。

“陈师兄，你终于醒了！”柳小茹急忙从怀里掏出一个小玉瓶，“这是我从丹房李师兄那儿求来的回春散，虽然只有三滴，但也许……”

陈凡接过玉瓶，入手温润。他打开瓶塞，一股淡淡药香飘出——以他前世见识过无数珍稀药材的眼光，这玩意儿大概相当于过期阿司匹林。

“花了什么代价？”陈凡问，声音沙哑。

柳小茹低下头：“我……我答应帮李师兄洗三个月的丹炉。”

陈凡沉默。他查看了这具身体的状况：丹田破碎，八条主脉断了七条，寒毒深入骨髓。别说修仙，能活过三天都算命大。而那三滴回春散，连止痛效果都有限。

更讽刺的是，原主的储物袋里，连一块完整的下品灵石都找不到——全变成了凌清雪洞府外随风飘扬的“雪花”（那是他每年冬天用灵力催生的冰晶花海），变成了她偶尔多看一眼的法宝残片，变成了她灵宠奢华的伙食费。

“系统检测到宿主处于濒死状态，符合激活条件。”

冰冷机械音突然在脑中响起。

“【超级舔狗返还系统】正在绑定……”

陈凡挑眉。来了，穿越者标配。但这名字……

“绑定成功。本系统旨在颠覆传统舔狗模式，打造新一代战略性投资人。”

“核心规则：宿主为选定目标付出任何形式的‘代价’（包括但不限于灵石、法宝、情感、时间、生命值），系统将根据目标‘气运等级’及‘付出行为的战略性评估’，给予随机倍率返还。”

“警告：直接向目标透露系统存在，将触发天道抹杀。”

“新手礼包已发放，请查收。”

陈凡心念一动，眼前浮现半透明面板：

【宿主：陈凡（陈不凡）】
【境界：炼气三层（濒死）】
【资产：下品灵石×0.5（碎块），回春散×3滴，破旧储物袋×1】
【系统等级：1（0/1000舔狗值）】
【当前可绑定目标：1人】
【新手礼包：无差别万倍返还体验券×1（限首次付出使用）】

简洁，直接，充满资本市场的味道。

陈凡目光落在最后的“无差别万倍返还体验券”上，眼神微动。

“柳儿，”他忽然开口，“这药你拿回去。”

柳小茹愣住：“师兄，你的伤……”

“我伤太重，这点药没用。”陈凡将玉瓶塞回她手里，“你资质不差，十五岁就炼气二层，别浪费在给我求药上。拿回去，关键时刻能保命。”

“可是——”

“这是投资。”陈凡看着她，用前世的语气说道，“我看好你的潜力。今日这三滴药，算我投的。”

柳小茹茫然地握着玉瓶，不明白陈师兄为何突然说这些奇怪的话。但她看见陈凡眼中的认真，还是点了点头，眼泪又掉下来：“师兄，你真好……可你自己怎么办？”

陈凡没回答，因为脑中系统提示音已经炸响：

“检测到宿主向目标‘柳小茹’（气运等级：玄阶下品，成长潜力：巨大）付出‘三滴回春散’及‘战略性投资建议’。”

“触发【无差别万倍返还体验券】！”

“计算中……”

“返还物品生成：”

“1.【极品回春丹×300瓶】（每瓶12粒，合计3600粒）——备注：市面流通的回春丹为上品，极品丹仅限内门长老炼制，一粒价值百枚下品灵石。”

“2.【先天木灵体觉醒碎片×1/3】——备注：集齐三枚碎片，可觉醒上古体质‘先天木灵体’，对草木灵气亲和度提升万倍，炼丹、疗伤天赋直达天阶。”

“3.【舔狗值+50】”

“所有返还物品已存入系统空间，宿主可随时提取。”

陈凡呼吸一滞。

他闭上眼，再睁开时，已经恢复了绝对的冷静。

“柳儿，你先回去。”他说，“三天后，你来这里找我。我给你一场造化。”

柳小茹懵懂地点头，一步三回头地走了。

木门关上，陈凡立即提取了一粒极品回春丹。丹药呈翡翠色，表面有九道天然丹纹，刚出现就满室生香，他体内肆虐的寒毒竟自行退避三舍。

吞下丹药。

温热洪流自喉咙炸开，瞬间冲刷四肢百骸。破碎的经脉如枯木逢春，以肉眼可见的速度修复、拓宽；丹田处涌起暖流，形成一个微小却无比稳固的气旋；深入骨髓的寒毒如雪遇沸水，尖叫着蒸发殆尽。

十息之后，陈凡睁开眼。

炼气三层巅峰。

距离四层只差一线。而且根基扎实得可怕——极品丹药毫无杂质，不会留下任何暗伤。

他感受着体内澎湃的灵力，又看向系统空间里堆成小山的丹药瓶，以及那枚悬浮的翠绿色碎片。

“投资回报率……”陈凡轻声自语，“这才是正确的打开方式。”

他起身，走到墙边摘下那个破旧的储物袋。原主所有的“资产”都在这里：半块碎裂的下品灵石，几件洗得发白的弟子服，一本基础《青云炼气诀》，以及——厚厚一沓泛黄的纸页。

陈凡抽出那些纸页。

《第一百零三次赠礼记录：凌清雪生辰，奉上百年冰莲，她看了一眼，未收。》

《第二百七十九次付出记录：为凌清雪试药，经脉受损，她赐下一颗下品疗伤丹。》

《第五百六十一次观察记录：清雪今日穿白衣，比昨日蓝衣更美。》

每一页，都是原主卑微到尘埃里的痴恋。直到最后一页，字迹潦草颤抖：

《第一千零一次记录：取回冰魄玄晶，寒毒入骨。她说……纯度太差，配给灵宠磨牙。》

陈凡静静翻完，将这些记录整齐叠好，放在桌上。

然后他从系统空间取出一粒极品回春丹，用指甲刮下些许粉末，融入清水，喂给了墙角一只瘸腿的野狗。

野狗舔舐几下，腿伤肉眼可见地愈合，毛色都油亮了几分。它摇着尾巴凑过来，蹭陈凡的裤腿。

“没有触发返还。”陈凡若有所思，“需要‘选定目标’，且必须是‘有价值的目标’。柳小茹有‘玄阶下品’气运，这狗……大概不入流。”

他蹲下身，摸了摸狗头：“你也算我在这世界的第一个‘非人脉资源’。”

就在这时，门外传来喧哗声。

“陈不凡！滚出来！”

木门被粗暴踢开，三个穿着外门执事服的中年人闯进来，为首者脸上有刀疤，炼气五层修为。

“李执事？”陈凡从记忆里认出此人，负责外门杂役分配，没少收受原主“上贡”给凌清雪的灵石。

“陈不凡，你倒是命硬。”李执事扫了他一眼，眼中闪过一丝惊讶——这废物不是快死了吗？怎么气色这么好？

但很快，他的目光落在桌上那沓记录纸上，嗤笑一声：“还在这写你的痴心妄想呢？正好，今天来通知你两件事。”

他竖起一根手指：“第一，你已连续三年宗门考核不合格，按律应逐出山门。但念在你对凌师姐一片痴心，长老特许你再留一个月——下个月的宗门小比，你若无法进入前三百名，就收拾铺盖滚蛋。”

外门弟子三千，前三百意味着至少炼气六层。原主在资源全数奉送的情况下，苦修百年才到三层，一个月？痴人说梦。

陈凡面色平静：“第二件？”

李执事露出贪婪的笑容：“第二，你去年借了我五十下品灵石，说是要给凌师姐买生辰礼。现在连本带利，该还一百了。”

记忆涌上：原主确实借了，但当时说好一年还五十五。李执事这是趁火打劫。

“我现在没钱。”陈凡实话实说。系统空间里丹药价值连城，但直接拿出来，等于小儿持金过市。

“没钱？”李执事冷笑，一挥手，“搜！看看这破屋里还有什么值钱的！”

两个跟班就要动手。

“等等。”陈凡开口。

他从怀中——实则是系统空间——取出一个小玉瓶，倒出一粒丹药。正是极品回春丹，丹纹流转，宝光莹莹。

屋内灵气浓度瞬间上升了一个档次。

李执事眼睛瞪大，呼吸急促：“这、这是……极品丹药？！你怎么会有——”

“我怎么有的，不重要。”陈凡把玩着丹药，“这一粒，买我清净到小比之前，够不够？”

“够！够！”李执事伸手就要拿。

陈凡却收回手：“口说无凭。立个天道契约吧——此丹给你，一个月内，你和你的手下不得以任何理由骚扰我。违约者，心魔反噬。”

天道契约是修仙界最严厉的约束，直接作用于道心。

李执事脸色变幻，但看着那粒极品丹药，终究贪念压过一切：“好！”

两人滴血成契，金光一闪，契约成立。

陈凡这才把丹药递过去。李执事抢过，如获至宝，带人匆匆离开——他得赶紧把这宝贝藏起来，或者献上去换个内门靠山。

木屋重归安静。

陈凡坐下，看着系统面板上新的提示：

“检测到宿主向目标‘李执事’（气运等级：黄阶下品）付出‘一粒极品回春丹’。”

“目标气运等级过低，付出行为缺乏战略性，返还倍率：0.1倍。”

“返还：下品灵石×10（按丹药价值十分之一折算）”

“舔狗值+1”

果然。陈凡验证了猜测：系统不是做慈善，它鼓励的是“战略性投资高潜力目标”。李执事这种货色，连本都回不来。

不过也好，用一粒对他而言无限供应的丹药，换一个月清净发展期，这交易本身就有战略价值。

陈凡收起那十块下品灵石，开始盘算。

首先，修复身体只是第一步。这世界实力为尊，炼气三层连蝼蚁都不如。

其次，他需要迅速积累启动资本。系统返还虽好，但前提是得有“第一桶金”去投资。

最后，也是最重要的——选定哪些“高价值目标”进行投资？

柳小茹的“玄阶下品”气运就有如此回报，那么“天阶”呢？记忆中，凌清雪是“地阶上品”冰灵根，已是青云仙宗百年一遇的天才。那天阶该是什么存在？

还有这系统的终极目的……陈凡不相信天上会掉馅饼。所谓的“颠覆传统舔狗模式”，背后是谁在布局？与那垄断飞升的“集团”是否有关？

一个个问题在脑中盘旋。

窗外，夕阳西下，将青云仙宗的七十二峰染成金色。飞剑流光划过天空，仙鹤长鸣，云海翻腾。

这是一个伟力归于自身的世界。

也是一个……尚未被资本染指的世界。

陈凡站起身，走到窗边。远处最高的那座雪峰，就是凌清雪的“冰魄峰”。此时峰顶亮起清冷光芒，那是她在修炼。

原主曾仰望那光芒百年，像仰望遥不可及的月亮。

陈凡也看着那道光芒，眼神平静得像在看一支K线图。

“凌清雪，”他轻声自语，“地阶上品气运，青云仙宗圣女，现年一百二十七岁，金丹初期修为，性格冰冷，追求者众多，但从未对任何人假以辞色。”

“从投资角度评估：属于‘明星型项目’，知名度高，成长性确定，但入场成本极高，竞争激烈，且项目方（本人）极度不配合。”

“结论：短期不宜重仓。”

他收回目光，看向更远处的群山，以及群山之外看不见的广阔天地。

“柳小茹，玄阶下品，十五岁，父母双亡，无依无靠，性格坚韧，对我有基础信任度。”

“结论：低成本天使轮标的，值得长期培养。”

金融巨鳄的直觉在复苏。

陈凡从系统空间取出那枚【先天木灵体觉醒碎片】，翠绿色的晶体在掌心流转着深邃光华。集齐三枚，就能觉醒上古体质——这是足以让任何宗门疯狂的至宝。

而第一枚，来自对柳小茹三滴过期药水的“投资”。

“倍率……”陈凡握紧碎片，“这才是我要的杠杆。”

他盘膝坐下，开始运转《青云炼气诀》。极品回春丹的药力还有大半沉积在体内，需要彻底炼化。

灵气如溪流汇入丹田，气旋缓缓转动。炼气三层到四层的壁垒，在磅礴药力面前薄如窗纸。

两个时辰后，月上中天。

陈凡睁开眼，眸中精光一闪而逝。

炼气四层，成。

他起身，感受着体内比之前强横数倍的灵力，以及——门外那道微弱的呼吸声。

“柳儿？”陈凡推开门。

柳小茹抱着膝盖坐在门槛边，已经睡着了。听到动静，她慌忙起身：“师兄！我、我不是故意打扰，我只是……睡不着，想来看看你怎么样了……”

月光下，少女脸上泪痕未干。

陈凡看着她，忽然问：“柳儿，你想变强吗？”

柳小茹愣住，然后用力点头：“想！我想像内门的师姐们一样，御剑飞行，降妖除魔，保护想保护的人……可是我的资质……”

“资质可以改变。”陈凡伸出手，掌心里躺着一粒极品回春丹，“这粒丹药，能洗经伐髓，提升资质。但过程会很痛苦，你愿意试试吗？”

柳小茹看着那粒宝光流转的丹药，又看向陈凡的眼睛。她没有问这丹药从哪来，也没有问为什么给她。

她只是跪下，磕了一个头：“陈师兄再造之恩，柳儿永世不忘。”

“不用跪。”陈凡扶起她，“这是投资。你变强了，将来要还的。”

柳小茹似懂非懂，但眼神坚定：“柳儿一定会还！百倍千倍地还！”

陈凡笑了。他让柳小茹服下丹药，然后守在旁边，用灵力引导药力化开。

痛苦的低吟声在木屋中响起，但少女咬紧牙关，没有哭喊。

窗外，青云仙宗的夜色深沉如墨。

陈凡看着柳小茹身上逐渐泛起的翠绿色光华，以及系统面板上缓慢跳动的【先天木灵体觉醒进度】，知道自己的第一笔真正投资，正在产生回报。

远处冰魄峰的光芒依旧清冷。

陈凡举起手，对着那方向虚握，然后缓缓翻转手掌。

仿佛要将那座山，连带着这个世界的旧规则，一起颠倒过来。

“从今天起，”他对着夜色低语，“修仙界的玩法，该换一换了。”

系统面板在眼前微微一亮，像是在回应。

新的提示浮现：

“主线任务触发：【资本的萌芽】”

“任务目标：在一个月内，建立初步的资本积累，并拥有至少三名‘战略级投资目标’。”

“放心，”他说，“前世我能从华尔街实习生爬到千亿规模，这一世……”

“我要让整个修仙界，都学会看K线图。”

月光洒落，木屋内的少女身上绿光渐盛。

而新的传奇，在这一夜悄然萌芽。

距离宗门小比，还有二十九天。
